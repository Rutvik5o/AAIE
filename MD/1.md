Changes from the plan:

- Model: Groq has retired llama-3.3-70b-versatile, so the agent uses openai/gpt-oss-120b, which your key can access.
- Environment: AAIE1 is a plain Python venv. Conda kept failing on your network.
- Data: there are 13 test cases rather than 12. The handbook ended up at about 3,150 words, a bit longer than planned.

What I fixed during testing:

- Login crash: the log-cleaning code broke the audit log entry for a failed login. Fixed.
- Memory: only one of two facts was being saved. Both now save.
- Tickets: the agent asked for confirmation in text instead of showing the Approve/Reject card. It now uses the card.
- Audit gap: requests for another student's data weren't logged when the model refused without calling a tool. They're now recorded as access_denied.
- Unwanted ticket: in one evaluation run, the agent created a ticket on the pet-policy question instead of just offering one. A stricter prompt rule fixed it; the README lists this as an observation.
- Grader bug: it failed a correct answer because the model wrote "CC‑2" with an unusual hyphen. It now normalises dashes.

About the numbers: three cases took 7–14 s because of Groq free-tier rate limits; a normal reply takes 1–3 s, and the README table marks those cases. The 13/13 is from one run, and an earlier run got 12/13 (the unwanted ticket), so results can vary slightly between runs.

Not yet checked: I confirmed the frontend reaches every backend endpoint, but I haven't clicked through the UI in a browser. Please look over the design and animations yourself.

Leftover test data: the testing left a couple of tickets in data/tickets.json, two remembered facts for S1001, and entries in the audit log. They're harmless demo data. To start clean, empty them or click "Forget all" in the UI.
